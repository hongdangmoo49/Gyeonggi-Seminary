## Phase 0 — 설정 (1시간)

| 작업 | 상세 |
|------|------|
| TypeScript 설치 | `npm install -D typescript @types/react @types/react-dom` |
| tsconfig.json 생성 | `strict: true`, `jsx: "react-jsx"`, `allowJs: true` |
| vite.config.ts 전환 | `vite.config.js` → `vite.config.ts` (Vite가 기본 지원) |

tsconfig.json 기본 설정:
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "bundler",

    "noEmit": true,
    "baseUrl": ".",
    "paths": { "@/*": ["src/*"] }
  },
  "include": ["src", "vite-env.d.ts"]
}

## Phase 1 — 타입 정의 파일 (2~3시간)

모든 컴포넌트 마이그레이션 전에 공통 타입을 먼저 정의합니다.

```
핵심 타입 목록:

// 인증

Comment           — id, author, date, content
BoardKey          — 'free' | 'notice' | 'academic' | 'prayer' | 'books' | 'alumni'

// 동영상/문서
Video             — id, category, title, professor, date, duration, thumbnail
Document          — id, category, title, fileType, size, date, downloads

// 네비게이션
NavItem           — label, path?, icon, children?

// 컴포넌트 Props
PageBannerProps   — title, subtitle?, en?

## 주의사항

1. **한 번에 하나씩** — 파일 단위로 전환하고 매번 빌드 확인
2. **allowJs: true** — Phase 5까지 JS/TS 혼용 가능
3. **CSS Modules** — `*.module.css` 파일은 변경 불필요, import 시 타입 선언만 추가
4. **Firebase 타입** — `firebase` 패키지에 타입이 내장되어 있어 `@types/firebase` 불필요
5. **react-icons** — `@types/react-icons` 불필요 (내장 타입)
