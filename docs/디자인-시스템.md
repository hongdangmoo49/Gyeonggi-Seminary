# 경기신학교 웹사이트 디자인 시스템

## 디자인 원칙

- **신뢰성**: 신학교의 정체성에 맞는 차분하고 권위 있는 톤
- **접근성**: 모든 연령층이 쉽게 사용할 수 있는 직관적 UI
- **일관성**: CSS 변수를 통한 통일된 디자인 톤

## 애니메이션

모든 keyframes는 `src/styles/variables.css`에 글로벌로 정의되어 있으며, CSS Modules에서 참조합니다.

| 이름 | 설명 | 사용 위치 |
|------|------|----------|
| `fadeIn` | opacity 0→1 | 탭 전환, 게시글 상세, 폼 |
| `slideUP` | 아래에서 위로 등장 | 로그인 모달 |
| `slideDown` | 위에서 아래로 등장 | 헤더 드롭다운 |
| `pageEnter` | opacity + translateY(8px) | 페이지 전환 시 |
| `spin` | 360도 회전 | 로딩 스피너 |

### 트랜지션 변수

| 변수 | 값 | 용도 |
|------|-----|------|
| `--transition-fast` | 0.2s ease | 호버, 포커스 |
| `--transition-base` | 0.3s ease | 슬라이드, 모달 |
| `--transition-slow` | 0.5s ease | 느린 트랜지션 |

## UX 패턴

### 로딩 상태
- `SkeletonList` 컴포넌트: shimmer 애니메이션 스켈레톤 (게시글 목록, 관리자 테이블)
- `LoadingSpinner` 컴포넌트: 회전 스피너 + 텍스트 (AdminAdmins)
- Board, Community, AdminPosts, AdminUsers에 SkeletonList 적용

### 빈 상태
- `EmptyState` 컴포넌트: 아이콘 + 제목 + 설명
- PostList에 적용 ("게시글이 없습니다")

### 토스트 알림
- 글 작성/수정/삭제 성공 시 `toast.success()`
- 관리자 권한 변경 시 `toast.success()`
- 권한 없는 삭제 시 `toast.error()`
- 로그아웃 시 `toast.info()`
- 우측 상단 고정, 3초 후 자동 사라짐, slideIn/slideOut 애니메이션

### 확인 다이얼로그
- `window.confirm()` 대신 커스텀 `ConfirmDialog` 사용
- Board, Community, AdminPosts, AdminUsers의 삭제 확인에 적용
- `useConfirm()` 훅: `const ok = await confirm('메시지')`

### 에러 상태
- `ErrorBoundary`: 전역 에러 캐치 + 재시도 버튼
- 폼 유효성: 인라인 에러 메시지 (빨간색 배경)

### 권한 기반 UI
- 삭제 버튼: 관리자만 표시
- 수정 버튼: 작성자 + 관리자 표시
- 글쓰기 버튼: 로그인 사용자만 표시
- 관리자 메뉴: 관리자만 헤더에 표시

### 페이지 전환
- 라우트 변경 시 `pageEnter` 애니메이션 (0.3s)
- scroll-to-top: Layout + AdminLayout 모두 적용
